Dogechain Wallet is a free, open-source, non-custodial Dogecoin wallet for Windows, macOS and Linux, published by the Dogechain Developments GitHub account. It syncs with the Dogecoin network through Simplified Payment Verification in minutes rather than downloading the full chain, keeps keys on your device, and includes a built-in swap. This GitHub page is the product home: the application repository, the tagged release with installers and checksums, the existing documentation repository, and the learn guides for recovery, transactions, swaps and installation.
